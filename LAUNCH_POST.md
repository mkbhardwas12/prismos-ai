PrismOS-AI v0.6.0 is on GitHub Releases.

It is a desktop app that talks to a local Ollama model. Drop a PDF (or
DOCX / PPTX / XLSX), ask a question, keep the answer on the laptop.
Works with Wi-Fi off. MIT.

Installers: Windows x64 `.msi`/`.exe`, macOS Apple Silicon + Intel `.dmg`,
Linux x64 AppImage + `.deb`. Linux ARM is not published.
